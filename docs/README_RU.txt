Arknights RU Independent v0.15 — перевод оригинальной Arknights (глобальный PC-клиент)

ПРОДВИЖЕНИЕ
- UI string_map: 2544 из 2711 ключей с русским адресным вариантом.
- 167 прочих ключей оставлены как служебные форматы, их менять нельзя без контекста.
- Сюжет 0-1: 138 реплик, сюжет 0-2: 99 реплик. Всего 237 черновых переводов.
- Архив сохраняет прежние черновики предметов/реплик/врагов, но они ещё не окончательные.
- Это НE устанавливаемый русификатор: отсутствует проверенная интеграция с игрой.

ЧТО НОВОГО
- story/story_0-2_ru_v015.json: адресный русский перевод сцены 0-2.
- story/story_main_0-1_0-2_ru_v015.json: оба эпизода, 4 сценических файла.
- scripts/apply_ru_story.py: локальная предпросмотровая сборка без изменения клиента.
- PREVIEW_STORY_0-1_0-2.bat: загрузка CN/EN + проверка Git SHA-1 + сборка RU-версий.
- исправлен URL загрузки английского первоисточника: репозиторий использует ветку main.

ЧТО НЕ ПРОВЕРЕНО
- Работа установщика/загрузчика в клиенте.
- Реальная загрузка сценариев из Windows и совместимость с изменившимися будущими версиями.
- Полная литературная редактура, качество размещения текста по ширине в UI.

Проверку в игре пока проводить не нужно. Следующие этапы: сюжетные главы и предметные описания.
