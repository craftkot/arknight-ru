## Ограничения

Переводы являются **первым черновиком**, редакторская проверка остаётся. `PREVIEW_STORY_v0.17.bat` загружает версии сценариев из комьюнити-архивов, проверяет контрольные Git blob SHA-1, затем создаёт приватные локальные копии на русском. Архив не содержит полнотекстовые оригинальные сценарии, EXE или DLL; игра не изменяется. Внедрение в клиент не проверялось.
