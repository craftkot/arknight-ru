# Arknights RU v0.14 — первый сюжетный перевод (эпизод 0-1)

Статус: **138 русских реплик — первый редакторский черновик**. Режим: CN → RU с контролем по EN.

**Состав:** `level_main_00-01_beg.txt` — 61 реплика; `level_main_00-01_end.txt` — 77 реплик. Переведены обе текстовые сцены этапа 0-1. Это НЕ перевод сюжетных глав целиком.

## Проверяемые источники

- CN: https://github.com/Kengxxiao/ArknightsGameData/tree/master/zh_CN/gamedata/story/obt/main
- EN: https://github.com/Kengxxiao/ArknightsGameData_YoStar/tree/master/en_US/gamedata/story/obt/main
- Исходные версии привязаны к git blob SHA-1 в файле `story/story_0-1_ru_v014.json`. Это зеркала сообщества, не официальная публикация автора.
- Число реплик по двум языкам одинаково; ПОСТРОЧНЫЕ соответствия редакторски сверены по смыслу, но возможны недостающие сюжетные ветвления и различия клиентских версий.

## Как посмотреть русский сценарий без изменения игры

1. Распакуйте полный проект на Windows.
2. Установите Python 3, если его нет.
3. Запустите `PREVIEW_STORY_0-1.bat`. Он загрузит точные CN и EN файлы, проверит их версии и соберёт русский вариант локально.
4. Результат: `output/story_ru_preview/ru/obt/main/level_main_00-01_beg.txt` и `level_main_00-01_end.txt`.
5. Альтернатива: скачайте эти четыре текстовых файла вручную и положите в `source/story/{cn,en}/obt/main/`, после чего выполните:

```
python scripts/apply_ru_story.py --source source/story --output output/story_ru_preview --translations story/story_0-1_ru_v014.json
```

Утилита работает с копиями текстов в папке проекта и **не обращается к игровой папке**. Она ничего не устанавливает в клиент и не модифицирует AssetBundle. Если Git-версии поменялись, строгая SHA-1 проверка запретит подмену — это безопасное поведение. В этом случае нужен новый разбор источников, нельзя просто отключать проверку.

## Переводческие решения и спорные термины

- `整合运动` → «Воссоединение» (EN `Reunion`); это рабочая редакторская форма, уточнить по принятому русскому глоссарию.
- `矿石病` → «орипатия»; `感染者` → «заражённые»; `罗德岛` → «Родос Айленд».
- `天灾` → «Катастрофа», с прописной буквы в контексте бедствия Терры.
- `切尔诺伯格人` → «жители Чернобога», чтобы не придумывать неблагозвучный демоним.
- На реплике 24 вступительной сцены учтён мотив страданий поколения родителей, обозначенный в китайском тексте более конкретно, чем в английском.
- `凯尔希` → «Кальцит»: рабочее написание; возможна смена после проверки всего глоссария.
- Неформальные имена, восклицания и интонация сохраняют характер персонажей, а не буквально следуют синтаксису EN.
- `{@nickname}` сохраняется побайтно в каждой соответствующей реплике. В сценарии предпросмотра переводятся также **отображаемые имена персонажей** в атрибуте `[name="..."]` по явному белому списку, другие команды не трогаются. Есть ключ `--keep-en-speaker-tags`.

## Проверка и ограничения

- 138/138 диалоговых позиций имеют перевод; 61 + 77 подтверждены отдельно по CN и EN зеркалам.
- Строгая сверка Git blob SHA-1 CN/EN, количества диалогов, тегов и управляющих строк.
- Локальные юнит-тесты проверяют сохранение команд, перевод имён и запрет записи при изменённой версии источника.
- В этой среде нет прямого доступа к GitHub из Python, поэтому локальная интеграционная проверка с **подлинными скачанными** файлами не проводилась; соответствующие файлы и их Git blob SHA-1 подтверждены через GitHub API.
- Не тестировалось в Arknights; возможны правки стиля, терминологии, полей имени и отображения в клиенте. Никакой заявленной «готовности всей истории» нет.
