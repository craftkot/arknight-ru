# Мемуары тёмных ночей — DM-2, до боя

Статус: первый черновик; китайский текст — источник смысловых нюансов, EN — сверка по репликам.

- **Инес**: сухая, недоверчивая, резкая. **W**: саркастичная, беззаботная нарочито; **Хёдерер**: сдержанный, прагматичный.
- Первый бой: W раскрывает предательство отряда наёмников и использует лагерные заряды, чтобы задержать преследование.
- Далее отряды встречают колонну Бабеля. Инес видит очертание необычного груза, заключительная строка — «Остов?».
- В источнике 132 именные реплики + 5 повествовательных строк. Плейсхолдеров нет.
- Не включать полные CN/EN сценарии в дистрибутив; они отдельно загружаются из источника с проверкой sha.
- Литературная редактура и проверка в клиенте ещё впереди.
