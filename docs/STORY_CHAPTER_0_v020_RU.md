# Аркнайтс — эпизод 0: полный черновик основного сценария

Глава 0 в архиве сюжетов `obt/main` содержит 12 файлов `level_main_00-*.txt`. В этом проекте они все имеют первый русский черновой перевод: **654 реплики**. Это не вся история Arknights и не включая сторонние файлы вроде обучения/воспоминаний.

## Источники

- CN: https://github.com/Kengxxiao/ArknightsGameData/tree/master/zh_CN/gamedata/story/obt/main
- EN: https://github.com/Kengxxiao/ArknightsGameData_YoStar/tree/main/en_US/gamedata/story/obt/main
- Для каждого файла записан Git blob SHA1; менять версии бесконтрольно запрещено.

## Сценарий 0-11: спорные варианты

1. `上城区` → «верхние районы Чернобога»; уточнить по принятой топографии локации.
2. `耀骑士` → «Сияющий рыцарь»; согласовать с будущим общим глоссарием.
3. `塔露拉姐姐` → «сестрица Талула»; отражает близкое, не формальное обращение.
4. `源石 / 矿石病` в предыдущих сценах → «Ориджиниум / Орипатия».
5. `Dr.{@nickname}` и другие игровые маркеры не должны терять переменную `{@nickname}`.

## Как получить русские копии сцены

Распаковать проект, установить Python 3, запустить `BUILD_CHAPTER_0_RU.bat`. Он **не меняет игру**: скачивает только CN/EN сценарии из открытых архивов, проверяет их сохранённые версии и создаёт копии с русскими репликами в `output/story_ru_preview_chapter_0/ru`.

Это не автоматический перевод следующей главы. Для дальнейших глав нужно сначала перевести и проверить их исходные реплики.
