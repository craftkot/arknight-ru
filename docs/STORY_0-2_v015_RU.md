# Сюжет 0-2 — CN → RU, EN для сверки

Переведены 48 реплик перед боем и 51 после него. Временные художественные переводы,
требуют второго редакторского чтения. Дата сборки: 2026-10-29.

## Источники
- CN: https://github.com/Kengxxiao/ArknightsGameData — zh_CN/gamedata/story/obt/main/
- EN: https://github.com/Kengxxiao/ArknightsGameData_YoStar — en_US/gamedata/story/obt/main/

Имена файлов, их SHA1 Git blob и порядковые номера реплик записаны в JSON, исходники
не вложены. Скачивание через README/BAT предназначено только для частной проверки.

## Принципы
1. Русский перевод основан на китайском тексте.
2. Английская версия проверяет смысл, но не подменяет китайский оригинал.
3. Переменные, музыка, теги, анимации и порядок реплик не изменяются.
4. Сравнение производится со строго известной версией исходного сценария.
5. Никакой модуль игры, DLL или Unity AssetBundle не изменяется.

## Проверка
Запустите PREVIEW_STORY_0-1_0-2.bat из распакованного полного архива,
имея Python 3 и доступ к GitHub. Результат сохранится в output/story_ru_preview_v015/ru/obt/main.
Если GitHub обновился, генератор откажется формировать превью до повторной сверки.
Не копируйте сценарии вручную в папку игры: готового механизма внедрения пока нет.
