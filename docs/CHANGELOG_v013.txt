Arknights RU v0.13 — 2026-10-29

Результат этого цикла
- +111 перевода реальных EN UI-ключей.
- Всего 2544 / 2711 интерфейсных ключей имеют русский адресный черновик (93.84%).
- 167 остальных ключей — технические форматирующие шаблоны,
  которые сохранены 1:1; им НЕ нужен русский текст.
- Проиндексированы ВСЕ 2711 строк, но это не значит «вся игра переведена».
- 2433 старых адресных переводов сохранены точно.
- 54 новых переводов требуют уточнения оригинальных названий/событий в CN.
- Не выполнена литературная редактура всего UI, его ширины в элементах игры, проверка патча.

Новые файлы
- drafts/v013_new_ui_keyed.tsv — новый перевод по ключу, EN и RU рядом.
- reports/v013_format_unchanged.tsv — не переводить (счётчики, форматы, символы).
- reports/QA_v013.json — измеримые показатели и ограничения.
- scripts/validate_v013.py — полная структурная проверка.
- scripts/fetch_story_pair.py — вручную загрузить ОДНУ парную CN/EN сцену.
- scripts/align_cn_en_story.py — экспорт двух текстов в таблицу для редактора.

Парный сюжет с китайского:
  python scripts/fetch_story_pair.py obt/main/level_main_00-01_beg.txt --out source/story
  python scripts/align_cn_en_story.py --cn source/story/cn --en source/story/en --out story_work/00-01.tsv
  python scripts/test_fetch_story_pair.py

Источники: GitHub community mirror Kengxxiao/ArknightsGameData, Kengxxiao/ArknightsGameData_YoStar.
Это сторонние слепки, версии могут различаться. Путь CN не идентичен пути EN по названию
персонажей/количеству сцен — проверяйте структуру сцены до перевода.
Код не скачивает оригиналы автоматически во время сборки. Пользователь сам запускает загрузку нужной пары.
Не распространяйте полученные исходные сюжетные файлы, если у вас нет прав.

Ограничение: v0.13 — рабочая база перевода; не готовый установочный патч.
Результат должен быть проверен в живом клиенте после редакторской вычитки.
