# Arknights RU v0.52 — единый пакет BepInEx/XUnity для Yostar Global PC

Корень игры: D:\GOG Games\YostarGames\Arknights_EN\

Это экспериментальный дополнительный перевод UI, **не DLL, не установленный игровой патч и не полноценная замена всех ресурсов интерфейса**. Существующие семь пользовательских TXT остаются без изменений.

## Установка

1. Полностью закройте игру и лаунчер.
2. Создайте резервную копию Arknights_EN\BepInEx\Translation\ru\Text вне папки игры.
3. Распакуйте ZIP непосредственно в корень Arknights_EN, где находится BepInEx. Добавятся 8 новых TXT в BepInEx\Translation\ru\Text: ArknightsRU_01_MenuAndSettings.txt и так далее до ArknightsRU_08_Misc.txt.
4. Запустите BACKUP_OLD_OVERLAYS_v052.cmd из корня игры. Скрипт **переместит** старые экспериментальные файлы v0.48, v0.49, v0.50 и v0.51 из Text в BepInEx\Translation\ru\Backup_before_v052. Он не удаляет и не меняет исходные семь TXT.
5. Запустите игру, проверьте вход, настройки, список операторов, главную панель и базу.

Не удаляйте исходные ArknightsRU_UI.txt, ArknightsRU_Additional.txt, ArknightsRU_ItemsAndCombat.txt, ArknightsRU_OperatorLines.txt и _Preprocessors.txt / _Postprocessors.txt / _Substitutions.txt. Их текст в ZIP не распространяется: это ваши существующие файлы, которые новый пакет дополняет.

## Что изменено

* В один пакет объединены 1312 отдельных XUnity-пар репозитория и проверенные по скриншотам дополнительные UI-коды v0.49–v0.51, с устранением повторных английских ключей.
* Учтены 489 английских ключей в исходных TXT, чтобы новый набор не конфликтовал с установленными переводами.
* Новые записи разнесены по файлам: меню/настройки, база, операторы, бой, магазин, сюжет/ивенты, системные сообщения и остальное.
* Опасно универсальные замены ON, OFF, Full, Free и подобные специально исключены. Для узких подпунктов применяются короткие русские надписи, когда это не затрагивает исходный перевод.
* AUDIT_SCREEN_LABELS_v052.json содержит проверку английских строк из предоставленных скриншотов.

## Известные ограничения

Ключ в XUnity, например Terminal=Терминал, НЕ гарантирует появления перевода в конкретной панели: некоторые элементы Arknights могут быть спрайтами, ресурсами UI или использовать другой метод TextMeshPro, который не перехватывается. Количество файлов TXT само по себе не является доказанной причиной предыдущих сбоев авторизации.

2544 русских keyed UI-значения и 2062 строки Darknights Memoir остаются отдельными данными; они **не** становятся автоматически XUnity-строками. Полной проверки локализации через игровой клиент ещё нет.

## Откат

Закройте игру. Удалите только новые 8 файлов с префиксами ArknightsRU_01_ по ArknightsRU_08_ из Text. Если необходимо, верните прежние дополнения из Backup_before_v052 в Text. Перезапустите клиент.

Для диагностики присылайте скриншот английского UI, свежий BepInEx\LogOutput.log и AutoTranslatorConfig.ini. При проблемах авторизации сначала проверяйте вход со всеми 8 новыми файлами, а потом без них при том же сетевом соединении.
