# Arknights RU v0.48 — пакет для уже установленного BepInEx

Это перевод **оригинальной Arknights Yostar Global PC** (не Endfield).
Основа подготовлена для пути:
D:\GOG Games\YostarGames\Arknights_EN\BepInEx\Translation\ru\Text

## Установка за один шаг

1. Полностью закройте Arknights.
2. Для безопасности сделайте резервную копию папки
   Arknights_EN\BepInEx\Translation\ru\Text.
3. Откройте ZIP и перенесите папку BepInEx из него в
   D:\GOG Games\YostarGames\Arknights_EN\
   (то есть в корень игры, где уже существует BepInEx).
4. В результате добавится только файл
   BepInEx\Translation\ru\Text\ArknightsRU_ExpandedUI_v048.txt
   рядом с вашими ArknightsRU_UI.txt, ArknightsRU_Additional.txt,
   ArknightsRU_ItemsAndCombat.txt и ArknightsRU_OperatorLines.txt.
5. Никакие существующие семь TXT не заменяются; три служебных
   пустых файла _Preprocessors.txt / _Postprocessors.txt /
   _Substitutions.txt остаются как были.
6. Запустите игру и проверьте меню, базу, рекрутинг и боевые подсказки.

Для отката просто удалите ArknightsRU_ExpandedUI_v048.txt.
Перезапуск игры может потребоваться после изменений.

## Что именно добавлено

Из 1312 уникальных XUnity-пар репозитория v0.47 берутся только
строки, английские ключи которых ещё не присутствуют в четырёх
присланных вами непустых TXT (489 ключей). Сопоставление использует
короткий криптографический отпечаток ключа; оно не изменяет уже
установленные переводы.

Это экспериментальное **расширение UI**. 2544 ключа игрового
локализационного JSON не равны 2544 XUnity-парам: без английского
текста и подтверждённого механизма загрузки игровых ресурсов их
нельзя корректно подставить в этот формат.

**2062 строк Darknights Memoir сюда не включены.** Прямое копирование
переведённого JSON в XUnity не обеспечивает воспроизведение сюжетных
сцен; для них необходим отдельный проверенный метод загрузки.

## Ограничения

BepInEx/XUnity у вас уже присутствует. Мы не устанавливаем или
обновляем эти компоненты и не меняем файлы клиента. Реальная
совместимость дополнительных UI-записей с конкретной версией
Yostar Global PC пока не доказана. UI, нарисованный спрайтами,
такой словарь не переведёт. Возможны конфликты с другими модами,
ограничения античита или условиями игры.

Если после установки ничего не изменилось, пришлите:
- один скриншот английского элемента, который должен переводиться;
- BepInEx\LogOutput.log и AutoTranslator\Config.ini (удалите секреты,
  если они вдруг присутствуют);
- версию клиента и список установленных плагинов.
Так можно отличить проблему загрузки словаря от проблемы доступа к UI.
