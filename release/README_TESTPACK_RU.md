# Arknights RU v0.47 — тестовый пакет

**Это НЕ игровой патч и НЕ автоматический установщик.** Предназначено
для экспериментальной проверки русского текста в оригинальной Arknights
Yostar Global PC (английский клиент, НЕ Endfield / CN / TW).

## Содержимое
- Translation/ru/Text/Arknights_RU_UI_EXPERIMENTAL.txt — вручную
  подготовленные пары английский=русский для XUnity.AutoTranslator.
- translations/ui_keyed_all_ru.json — 2544 переведённых UI-ключа, только
  локализационные ДАННЫЕ, не готовый изменённый игровой ресурс.
- events/darknights_memoir_all_ru_v047.json — первый полный русский
  черновик 13 сцен Darknights Memoir (2062 реплики), НЕ готовый патч.
- scripts/ и BUILD_DARKNIGHTS_ALL_PREVIEW_v047.bat — безопасный
  предпросмотр, скачивающий отдельно CN/EN файлы с проверкой Git blob SHA.

В архиве нет DLL, инжекторов, исполняемых модов, сторонних лаунчеров,
исходных игровых файлов или средств записи в установленную игру.

## Проба интерфейса — ТОЛЬКО если XUnity уже работает

1. Полностью закройте Arknights, сделайте резервную копию папки переводов.
2. Проверьте, что ваш XUnity.AutoTranslator уже работает с этой игрой.
   Этот ZIP его НЕ устанавливает.
3. В конфигурации работающего XUnity язык источника должен быть en,
   цель — ru, а Directory — Translation\ru\Text (или иной путь,
   указанный в вашей действующей конфигурации).
4. Поместите только Arknights_RU_UI_EXPERIMENTAL.txt из папки
   Translation\ru\Text в соответствующую папку работающего XUnity.
5. Запустите игру, посмотрите меню. Если UI остался английским, это
   не доказательство ошибки перевода: плагин может не видеть UI-тексты.
6. Для отката удалите добавленный TXT, восстановите резервную копию.

НЕ копируйте этот архив поверх ресурсов Arknights, НЕ подкладывайте
его вслепую в DITF или другой сторонний русификатор. Совместимость
с ними отсутствует и не проверялась. Любое стороннее вмешательство в
клиент может нарушить пользовательское соглашение или привести к сбоям.

## Проверка сюжета отдельно от игры

На Windows при наличии Python 3 запустите
BUILD_DARKNIGHTS_ALL_PREVIEW_v047.bat. Он скачивает проверенные
версии CN/EN сценариев из публичных зеркал Kengxxiao и формирует
локальные предпросмотры в output/ без вмешательства в игровой клиент.
Нужен доступ к GitHub. Не распространяйте загруженные исходные файлы.

## Известные ограничения

- 13/13 сцен: литературный ПЕРВЫЙ черновик, без редакторской вычитки
  и без проверки в установленном клиенте.
- 2544 keyed UI-строки сами по себе не внедряются в игровой интерфейс.
- XUnity переводит лишь реально доступные ему текстовые элементы.
  Для оригинальной ПК-Arknights его работоспособность здесь не доказана.
- Если текст меню рисуется изображением или лежит в закрытом ресурсе,
  простой текстовый файл не сможет его заменить.
