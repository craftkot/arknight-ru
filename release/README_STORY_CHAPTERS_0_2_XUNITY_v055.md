# Тест сюжетного перевода Arknights 0–2 для Yostar Global PC

**Версия v0.55, только для оригинальной Arknights, не Endfield.**

Это тестовый **XUnity-словарь**, собранный из уже написанных русских черновиков 44 сцен / 2377 реплик глав 0–2. В ZIP лежат только 3 дополнительных TXT для XUnity, скрипт отката, отчёт о покрытии и инструкция. BepInEx, DLL, AssetBundle, клиентские ресурсы и старые переводы **НЕ** заменяются. Систему авторизации этот пакет не патчит.

## Установка на твою сборку

1. Полностью закрой Arknights и Yostar Games Launcher.
2. Сохрани копию папки: D:\GOG Games\YostarGames\Arknights_EN\BepInEx\Translation\ru\Text (на всякий случай).
3. Распакуй ZIP прямо в D:\GOG Games\YostarGames\Arknights_EN\ — так, чтобы появились:
   - BepInEx\Translation\ru\Text\ArknightsRU_20_Story_Chapter0_TEST.txt
   - BepInEx\Translation\ru\Text\ArknightsRU_21_Story_Chapter1_TEST.txt
   - BepInEx\Translation\ru\Text\ArknightsRU_22_Story_Chapter2_TEST.txt
4. Остальные файлы (UI и тестовый объединённый v0.52) не трогай. Их менять для этого теста не нужно.
5. Запусти оригинальную Arknights и открой самый первый доступный диалог главы 0. Сравни **текст реплик**, а не графические названия глав.

## Если перевод не отображается

- В уже установленной конфигурации EnableTextMeshPro=True и EnableUGUI=True; это не гарантирует перехват всех текстовых элементов игры на IL2CPP.
- Alt+T — включение/отключение отображения переводов XUnity; Alt+R — повторная загрузка TXT; закрой и открой сцену, если она уже на экране.
- Если по-прежнему английские диалоги, пришли скриншот первого диалога **и свежий** BepInEx\LogOutput.log (в логах важно проверить время именно текущего запуска).
- В конфигурации AutoTranslatorConfig.ini у тебя MaxCharactersPerTranslation=200. В отчёте AUDIT_STORY_0_2_v055.json указано, сколько новых ключей длиннее 200 символов; такие строки могут игнорироваться плагином. Для их тестирования после резервного копирования конфигурации допустимо вручную поставить MaxCharactersPerTranslation=400 и перезапустить игру. Не повышай выше 400.
- Если автоперевод (не словарь) отключён, это нормально: точные пары должны работать без сетевого сервиса.

## Почему не все 2377 реплик в TXT?

Из исходных русских черновиков берутся точные **английские тексты реплик** после [name="..."]. Но XUnity — словарь по тексту, а не по идентификатору игровой сцены. Поэтому:
- короткие и слишком общие фразы сознательно не подменяются (иначе можно испортить меню/системные окна);
- если одинаковая английская реплика имеет разные русские переводы в разных местах, оба варианта исключаются;
- вырезаются ключи, уже имеющиеся в твоих 489 исходных TXT или общей UI-базе репозитория;
- динамические вставки (например, имя игрока) нельзя надёжно сопоставить простым буквальным ключом;
- текст слишком длинный для безопасного лимита, либо с проблемной структурой, исключён.

Точное число уникальных безопасных замен и потенциально покрытых реплик указано в AUDIT_STORY_0_2_v055.json и проверено сборщиком. **Оно НЕ означает**, что именно столько переводов было реально показано в клиенте.

## Откат

1. Закрой игру/лаунчер.
2. Запусти ROLLBACK_STORY_TEST_v055.cmd в корне Arknights_EN.
3. Скрипт **переместит только эти 3 новых TXT** в BepInEx\Translation\ru\Backup_Story_0_2_v055. Ни оригинальные пользовательские TXT, ни настройки игры не затрагивает.
4. Запусти игру снова.

## Техническое ограничение

Текущие 44 сценария переведены в repo как русский JSON. Официальный ПК-клиент не читает этот JSON напрямую. XUnity обычно перехватывает уже созданные UI-тексты Unity; его IL2CPP поддержка неполная. Если после установки в сюжете вообще ничего не переведётся, значит **точного словаря недостаточно**, и понадобится отдельная интеграция сюжетных ресурсов/хук текста, которую нельзя считать готовой без исследования конкретных файлов клиента и проверки совместимости. Этот архив не выдаётся за такой хук.

Исходные игровые китайские/английские сценарии не лежат в ZIP. При сборке сверяется Git blob SHA каждого EN-исходника, чтобы не спутать версию.
