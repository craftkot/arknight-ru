# Arknights RU — независимый черновой русификатор

Проект любительского перевода **оригинальной Arknights (Yostar Global PC)**. Это не Arknights: Endfield.

## Статус

Ветка импорта `import/v0.29` содержит актуальный рабочий набор переводов, скриптов и тестов. Первые черновики глав 0–2, а также фрагмент ивента Darknights Memoir; игровые файлы не патчатся автоматически. **Проект не проверен в клиенте.**

## Источники

Китайские и английские сценарии берутся раздельно из открытых баз данных; оригинальные игровые сценарии не входят в репозиторий. Проверяйте лицензии и права при публичном распространении.

## Безопасность

Не запускайте архивированные `UNSAFE`-варианты XUnity как готовые игровые патчи. Основной сценарный генератор проверяет хеши исходных файлов и сохраняет управляющие команды.
